
Dies ist eine statische Webseite, die einen Katalog von 100 Chanel-Parfümprodukten darstellt. Sie wurde aus einem PDF-Katalog erstellt und enthält:

- Eine HTML-Datei (`index.html`) mit einer übersichtlichen Produktliste
- Ein eingebundenes Stylesheet (`styles.css`) für ein klares, responsives Design
- 100 Produktbilder im Ordner `images/`

## Vorschau

Jedes Produkt zeigt:
- Produktnummer (z. B. FB-01)
- Bild des Flakons
- Produktname („Chanel“)
- Kapazität: 100ml / 3.4 oz

## Verwendung

### Lokale Vorschau:
1. Entpacke das ZIP-Archiv.
2. Öffne `index.html` in einem beliebigen Webbrowser.

### Veröffentlichung im Web:
Du kannst die Seite kostenlos veröffentlichen – z. B. mit:
- **GitHub Pages** (https://pages.github.com/)
- **Netlify** (https://app.netlify.com/drop)

Siehe Anleitung im Abschnitt unten für Details zur Veröffentlichung.
